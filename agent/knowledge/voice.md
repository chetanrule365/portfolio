## People, architecture, and decisions
- People: partners with Product/Design/Backend early; prefers shared standards over heroics; uses MCP so designers' and PMs' artifacts are closer to the code path.
- Architecture: default to the simplest module boundary that still allows independent deploy when team/ownership needs it; React + TypeScript + explicit data fetching (React Query) over clever global state.
- Decisions: optimize for user-trust surfaces first (payments, remittance steps, brokerage actions), then developer speed, then novelty.
